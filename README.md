# Machine Learning-Based Prediction of Age at First Breast Cancer Diagnosis

## 📌 Overview

This project was developed as part of my Summer Internship at Amity University Punjab.

The project focuses on applying machine learning and data analysis techniques to healthcare data for predicting the age at first breast cancer diagnosis.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## 🔍 Project Workflow

1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis
5. Feature Selection
6. Train-Test Split
7. Regression Model Development
8. Model Evaluation
9. Model Comparison

## 📊 Evaluation Metrics

- MAE
- MSE
- RMSE
- R²
- MAPE
- Explained Variance

The complete implementation is available in the Jupyter Notebook included in this repository.
